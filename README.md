# Мурдалитос 🦎⚡

Неоновый PWA-трекер привычек.

## Что внутри

- создание и удаление привычек;
- срок привычки в днях;
- ежедневная отметка выполнения;
- общий «заряд дисциплины» в виде батареи;
- серии, пропуски и динамика за 14 дней;
- штраф-задача за пропуски;
- локальное сохранение в браузере;
- резервная копия JSON + импорт;
- экспорт истории в CSV;
- PWA / установка на экран iPhone;
- Apple Touch Icon с неоновой ящерицей;
- офлайн-кэш через Service Worker;
- уведомления, пока приложение активно;
- `.ics`-напоминание для iPhone/календаря, чтобы уведомление работало и когда сайт закрыт.

## Быстрый запуск локально

Service Worker требует HTTP(S), поэтому не открывайте `index.html` через `file://`.

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`.

1. Загрузите содержимое проекта в ветку `main`.
2. В GitHub откройте **Settings → Pages → Source → GitHub Actions**.
3. Workflow автоматически опубликует сайт.

## Важно про напоминания на iPhone

Обычная статическая PWA без push-сервера не может гарантированно запускать JavaScript в закрытом состоянии. Поэтому:
- уведомления браузера срабатывают, когда приложение активно;
- у каждой привычки есть кнопка `◷`, которая скачивает повторяющееся `.ics`-событие с напоминанием для Календаря iPhone.

Для настоящих фоновых push-уведомлений понадобится небольшой backend/Web Push сервис.
